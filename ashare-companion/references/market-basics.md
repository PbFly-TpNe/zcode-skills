# A股交易规则速查

> 以下整理自截至 2025 年的公开规则。涉及具体数字的条目可能调整，回答前不确定就搜索核实"以交易所最新规定为准"。

## A股和港股、美股的核心区别

| | A股 | 港股 | 美股 |
|---|---|---|---|
| 交易制度 | T+1（当天买次日卖） | T+0 | T+0 |
| 涨跌幅 | 有（10%/20%/30%分板块） | 无 | 无 |
| 涨跌颜色 | 红涨绿跌 | 绿涨红跌（国际惯例） | 绿涨红跌 |
| 最小单位 | 100股（1手） | 每只股票手数不同 | 1股 |
| 结算货币 | 人民币 | 港币 | 美元 |
| 交易时段 | 9:30-11:30, 13:00-15:00 | 9:30-12:00, 13:00-16:00 | 盘前+常规+盘后，很长 |

| 板块 | 代码开头 | 日常涨跌幅 | 开户门槛 | 定位 |
|---|---|---|---|---|
| 沪市主板 | 60× | ±10% | 无 | 成熟大企业 |
| 深市主板 | 00× | ±10% | 无 | 成熟大企业（原中小板已并入） |
| 创业板 | 30× | ±20% | 10万资产+2年经验 | 成长型创新企业 |
| 科创板 | 68× | ±20% | 50万资产+2年经验 | 硬科技 |
| 北交所 | 8×/4×/92× | ±30% | 50万资产+2年经验 | 专精特新中小企业 |

ST 股：沪深主板 ±5%；创业板/科创板仍为 ±20%。新股：沪深各板块上市**前5个交易日不设涨跌幅**；北交所新股首日不设限、次日起 ±30%。

主要指数：上证指数（大盘）、深证成指、创业板指、科创50、北证50、沪深300（核心资产）、中证500（中盘）、上证50（超大蓝筹）。

## 委托与成交

- 买入申报：主板/创业板须为100股整数倍；科创板200股起、超出部分可1股递增；北交所100股起、可1股递增。
- 限价委托：指定价格，价格可控但可能不成交——**新手首选**。
- 市价委托：立即成交但价格不可控，涨跌停附近可能成交在很差的价格。
- T+1：今天买的股票明天才能卖；卖出所得资金当天可用于买入，次日可转出到银行卡。
- 同一人在同一市场最多可开3个A股账户。

## 交易费用

| 费用 | 收取方 | 费率 | 方向 |
|---|---|---|---|
| 佣金 | 券商 | 常见万1~万3（可谈），多数有单笔最低5元 | 买卖双边 |
| 印花税 | 国家 | 0.05% | 仅卖出 |
| 过户费 | 中国结算 | 0.001% | 买卖双向 |

示例：1万元买入再1万元卖出，按万2.5佣金（最低5元）计算——买入约5.1元，卖出约10.1元，一个来回约15元（0.15%）。佣金高低和"免五"与否对小资金影响明显，开户前务必问清。

## 开户流程

1. 条件：年满18周岁，本人身份证 + 本人银行卡（一类卡）。
2. 渠道：任选一家券商的 APP/官网线上办理（约15-30分钟）：上传身份证 → 视频见证 → 风险测评 → 绑定银行卡 → 设置密码。
3. 出账号：工作时间提交，一般当天至次日出资金账号。
4. 选券商看三点：佣金（含是否免五）、APP 好不好用、是否方便联系客户经理。基本不需要去营业部。
5. 提示：创业板/科创板/北交所有资产和经验门槛，新开户暂时不能买，主板股票和场内基金不受影响。

## 打新（新股申购）规则要点

- 门槛：申购日前20个交易日，沪市/深市账户日均持有对应市场的股票市值各≥1万元。
- 额度：沪市每1万元市值可申购1000股（以1000股为单位递增）；深市每5000元市值可申购500股（以500股为单位递增）。
- 流程：申购日委托申购 → 摇号 → 中签日缴款 → 上市。
- ⚠️ 中签≠稳赚：近年新股破发常见，申购前看一眼发行价对应的估值和行业。科创板/创业板打新需先开通对应权限。

## 分红与除权

- 现金分红才是真金白银；送股/转增只是股本数字游戏，总资产不变。
- 分红后股价相应调低（除息/除权），持股期间股价图会因此出现"跳水"假象，看长期图要用复权。
- 红利税：持股超1年免税；1个月至1年 10%；不足1个月 20%（按卖出时持股时长补扣）。

## 权威信息渠道

- **公告**：巨潮资讯网（cninfo.com.cn，证监会指定披露网站）、各交易所官网
- **监管**：证监会官网、上交所/深交所/北交所官网
- **投教课程（免费官方）**：上交所、深交所的投资者教育网站/公众号
- **行情工具**：各券商APP、同花顺、东方财富等（数据同源，选顺手的即可）
- **股民人数等统计**：中国结算官网

## 风险红线（值得原样告诉用户）

- 不出借、不租借自己的证券账户给他人操作（涉嫌违法）。
- 场外配资（非券商渠道的加杠杆）不受法律保护，是违法行为。
- 荐股群、"老师带单"、"内幕消息"、保本高收益承诺——绝大多数是诈骗，直接远离。
- 投资有风险，本资料为知识整理，不构成投资建议。
