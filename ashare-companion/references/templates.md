# 资讯整理模板

整理用户提供的资讯时，选用下面的模板，输出为结构化 Markdown。通用规则：

- **事实和解读分开写**：数字是事实，"利空/利好"是解读，不要混在一起冒充事实。
- **缺数据就标注**：写"未提供"或"需查证"，绝不编数字。
- **所有数据注明日期**：尤其是股价、市值这类每天变的东西。
- **保存为文件**：存到工作区 `notes/` 目录，文件名 `YYYY-MM-DD-主题.md`；对话里只给 3-5 句核心摘要。
- **结尾提示**：整理结果仅供参考，不构成投资建议。

## 模板1：个股速览卡

用于：用户提到某只股票，想快速了解它。

```markdown
# {公司名}（{代码}）速览卡
> 整理日期：{日期}｜数据来源：{来源}（数据截至：{日期}）

## 基本信息
- 板块/交易所：{沪深主板 / 创业板 / 科创板 / 北交所}
- 所属行业：{}
- 总市值：{}（截至{}）
- 最新股价：{}（截至{}，回答前需联网核实）

## 公司是干嘛的（一句话）
{用大白话说清主营业务，比如"卖白酒的，主打高端市场"}

## 近期大事
| 日期 | 事件 | 性质 | 备注 |
|---|---|---|---|
| {} | {} | 利好/利空/中性 | {} |

## 财务概览（最近一期财报）
| 指标 | 数值 | 同比 | 备注 |
|---|---|---|---|
| 营收 | | | |
| 归母净利润 | | | |
| 毛利率 | | | |
| ROE | | | |
| PE / PB | | — | 估值贵不贵要结合行业看 |

## 风险点
- {}（至少列 2-3 条：行业风险、经营风险、近期解禁/减持等）

## 一句话小结
{面向小白的大白话解读，标注"仅供参考，不构成投资建议"}
```

## 模板2：新闻要点整理

用于：用户贴来一条新闻/公告，想知道发生了什么、跟哪些股票有关。

```markdown
# 资讯整理：{标题}
> 来源：{}｜发布时间：{}｜整理时间：{}

## 事件一句话
{大白话说清发生了什么}

## 涉及公司/板块
| 公司/板块 | 代码 | 影响方向 | 影响逻辑（小白版） |
|---|---|---|---|
| {} | {} | 利好/利空/中性/存疑 | {为什么，一两句} |

## 需要留个心眼的地方
- 消息是否官方证实：{是/否/部分}
- 股价是否已提前反应：{查一下相关股票近期走势再下结论}
- 常见的过度解读：{比如"利好落地不等于马上涨"}

## 待核实清单
- [ ] {整理过程中没能确认的信息}
```

## 模板3：财报速读

用于：用户贴来财报数据/财报新闻，想看懂这份"成绩单"。

```markdown
# {公司} {报告期} 财报速读
> 数据来源：{来源}｜整理时间：{日期}

## 核心数字
| 指标 | 本期 | 同比 | 第一眼判断 |
|---|---|---|---|
| 营收 | | | 增/降/持平 |
| 归母净利润 | | | |
| 扣非净利润 | | | 和净利润差距大时要问为什么 |
| 毛利率 | | | 升/降 |
| 经营现金流 | | | 利润高但现金流差 = 警惕 |

## 三个亮点
1. {}
2. {}
3. {}

## 三个隐忧
1. {}
2. {}
3. {}

## 小白翻译
{这份财报用大白话说就是……两三句}
```
